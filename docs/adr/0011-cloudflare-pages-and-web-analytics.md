# Deploy with Cloudflare Pages and use Cloudflare Web Analytics

The public GitHub repository connects to Cloudflare Pages for free production and preview deployments. Cloudflare Web Analytics provides privacy-first traffic and performance analytics and is enabled only in production, so local development and tests do not emit analytics traffic. The project avoids cookies and personal-data analytics.

The deployment platform portion of this decision is superseded by ADR 0018.
